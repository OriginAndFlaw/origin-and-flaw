Privacy policy

Origin and Flaw Uploader. Last updated: 26 November 2026.

Origin and Flaw Uploader ("the tool") is a private tool used only by the owner of the YouTube channel Origin & Flaw (youtube.com/@OriginAndFlaw) to publish that channel's own videos.

What the tool accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload the channel's own videos and to set their titles, descriptions, thumbnails, captions, audio tracks and playlists. It accesses only the channel owner's own YouTube account.

What the tool does not do

  • It does not collect, store or process data about any other person or YouTube user.
  • It does not sell, share or transfer any data to third parties.
  • It does not use data for advertising.

Storage of credentials

The OAuth credentials are stored as encrypted secrets in the owner's private build settings and are used only to upload the owner's videos. The owner can revoke access at any time at myaccount.google.com/permissions.

Data retention and deletion

The tool stores no personal data. The only stored item is the channel owner's own OAuth token, kept as an encrypted build secret. Deleting that secret, or revoking the tool's access at security.google.com/settings/security/permissions, removes the tool's access immediately; nothing else needs to be deleted. Videos uploaded by the tool are the owner's own content on YouTube and can be deleted in YouTube Studio at any time.

YouTube API Services

This tool uses YouTube API Services (YouTube Data API v3) only to publish the channel owner's own videos.

Google and YouTube

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
